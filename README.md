# Portal VagouApp (`pvapp`)

Aplicativo mobile-first e marketplace público de agendamento de vagas imediatas e horários ociosos em salões de beleza, barbearias, estética e bem-estar.

## Como rodar localmente

```bash
npm install
npm run dev
```

## Como compilar para produção

```bash
npm run build:pages
```

Os arquivos compilados estáticos serão gerados na pasta `dist/`.
